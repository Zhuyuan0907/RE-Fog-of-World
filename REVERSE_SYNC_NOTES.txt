  - divide by 64 => exploration cell grid

  - blocks per document = 128 x 128
  - blockId = blockX + blockY * 128
  - documentId = documentX + documentY * 512

Sync format findings
- The 9 files in /Users/zhuyuanjiang/Downloads/Sync are zlib-compressed binary files.
- After decompression, they are not raw polylines and not a single row-major bitmap.
- Current highest-confidence structure:
  - first 128 pages are the root index
  - page size = 256 bytes
  - root index = 128 x 128 uint16 references
  - each non-zero reference points to 2 payload pages
  - each payload page decodes as 64 x 32 bits
  - two payload pages together form a 64 x 64 explored block
- This means Sync is much closer to explored-state block storage than GPS route storage.
